    Project Xanadu¶

    A Revolutionary Approach to Hypertext¶

    Welcome to Project Xanadu, a reimagined implementation of Ted Nelson's groundbreaking hypertext vision from 1960. Unlike the World Wide Web we use today, Project Xanadu was designed with fundamental innovations that could have transformed how we interact with information.

    Core Concepts¶

    Project Xanadu introduces several revolutionary concepts that challenge how we think about digital documents:

    🔗 Bidirectional Links¶

    Unlike traditional web hyperlinks, Xanadu links work in both directions. When Document A links to Document B, Document B automatically knows about the connection. This enables:

    • Automatic backlink discovery - see what references any document
    • Citation networks - explore knowledge graphs naturally
    • Unbreakable links - links maintained in a central registry never break

    Learn more about Bidirectional Links{ .md-button }

    📎 Transclusion¶

    Instead of copying content, Xanadu includes content by reference, maintaining an active connection to the source. This means:

    • Single source of truth - updates propagate automatically
    • Built-in attribution - source is always known and tracked
    • Synchronized content - changes flow to all references instantly

    Learn more about Transclusion{ .md-button }

    🔀 Parallel Document Structures¶

    Documents can exist in multiple contexts simultaneously, each with its own annotations and perspectives while sharing core content:

    • Multiple audiences - same content, different presentations
    • Contextual annotations - add notes without affecting the original
    • Shared updates - core content updates across all views

    📚 Version Tracking¶

    Every change is tracked automatically, creating a complete document history:

    • Time travel - view any previous version instantly
    • Change attribution - know who changed what and when
    • Branching narratives - multiple versions can coexist

    ⚖️ Copyright Management¶

    Content-level tracking of rights and permissions ensures proper attribution and compensation:

    • Micropayments - authors compensated for transcluded content
    • Automatic attribution - citations maintained automatically
    • Rights preservation - intellectual property tracked at content level

    Key Innovations¶

    1. Persistent, unbreakable links - Content-addressed, not location-addressed
    2. Transclusion over copying - Include by reference, not duplication
    3. Bidirectional connections - Navigate relationships in both directions
    4. Parallel visualization - Same content in multiple contexts
    5. Built-in version control - Complete document history automatically maintained

    Why Xanadu Matters Today¶

    While the World Wide Web won the hypertext wars, many of Xanadu's ideas are more relevant than ever:

    • Broken links plague the modern web - Xanadu's content addressing would eliminate this
    • Copy-paste culture loses attribution - Transclusion maintains connections
    • One-way citations make discovery hard - Bidirectional links enable knowledge graphs
    • Context collapse flattens meaning - Parallel documents preserve multiple perspectives

    Ted Nelson's Vision

    "The Web is a very shallow imitation of the ideas we had in mind. It's like the horseless carriage compared to what we were designing."
